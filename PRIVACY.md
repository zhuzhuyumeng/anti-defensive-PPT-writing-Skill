# Privacy / 隐私说明

本仓库发布中英文说明型 Skill、提示词与插件元数据。它不包含 MCP 服务、登录、遥测、网络上传或向维护者发送用户材料的运行时代码；本地构建脚本只读取仓库内的公开分发文件并生成 ZIP。

使用时，用户材料仍由所选 AI 产品、模型服务和其他主动使用的工具处理，其数据规则取决于相应服务及账户设置。本说明不替代这些服务的隐私政策，也不承诺整个宿主环境完全离线。用户无须向本项目维护者提交演示文稿或业务资料。

问题反馈：[GitHub Issues](https://github.com/zhuzhuyumeng/anti-defensive-PPT-writing-Skill/issues)。请勿在公开 issue 中粘贴私密材料。

---

This repository distributes instruction-only skills, prompts, and plugin metadata. It contains no MCP server, login, telemetry, runtime uploader, or code sending user material to the maintainer. The local build script reads public distribution files and writes a ZIP.

When used, material is processed by the chosen AI product, model service, and any other tools deliberately used. Their policies and account settings govern that processing. This notice does not replace those policies or promise that the host environment is offline. Users do not need to submit their presentations or business data to this project's maintainer.

Support: [GitHub Issues](https://github.com/zhuzhuyumeng/anti-defensive-PPT-writing-Skill/issues). Avoid posting private material in public issues.
